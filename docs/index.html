Toss

Share a file or folder with anyone on your local network in one command. The link expires on its own when time runs out.

Install View on GitHub

Install

macOS, Linux and Windows (Git Bash):

$ curl -o- https://raw.githubusercontent.com/snyype/toss/main/install.sh | bash

Share a file

$ toss -t 300 report.pdf
Sharing report.pdf (2.4 MiB) for 5m0s.
Download it from another device on the same network with:
  toss pull http://192.168.1.65:8080/my-pc/download/report.pdf
  curl -o "report.pdf" http://192.168.1.65:8080/my-pc/download/report.pdf
  or open in a browser: http://192.168.1.65:8080/my-pc/download/report.pdf

On the other device, copy the green toss pull line, open the link in a browser, or use curl. To resume an interrupted curl download:

$ curl -C - -o report.pdf http://192.168.1.65:8080/my-pc/download/report.pdf

Share a folder

$ toss photos
? photos is a folder (128 files, 342.5 MiB). Zip it and share as photos.zip? [Y/n] y
Zipping... ████████████ 100% 342.5 MiB/342.5 MiB  128/128 files
✓ Zipped 128 files into photos.zip (339.8 MiB) in 6.2s.
Sharing photos.zip (339.8 MiB) for 5m0s.

Toss asks before zipping; use toss -y photos to skip the question. The zip is made in a temp folder inside the Toss install directory and deleted when Toss exits. Your original folder is never modified.

Pull a file

$ toss pull http://192.168.1.65:8080/my-pc/download/photos.zip
  ████████████  100% 339.8 MiB/339.8 MiB 41.2 MiB/s   ETA 0s
✓ Downloaded photos.zip (339.8 MiB in 8.3s, avg 40.9 MiB/s)
Saved to: C:\toss\downloads\photos.zip

Files land in a downloads folder inside the Toss install directory, and the full path is printed at the end. toss stream <link> does the same thing. If a download is interrupted, run the same command again to resume; existing files are never overwritten (you get photos (1).zip instead).

See what you've sent

$ toss logs
TIME                 EVENT     FILE         CLIENT         SIZE      DETAILS
2026-11-14 20:23:02  share     report.pdf                  2.4 MiB   for 300s
2026-11-14 20:23:40  download  report.pdf   192.168.1.80   2.4 MiB   completed in 310ms
2026-11-14 20:28:02  end       report.pdf                            expired, 1 download(s)

Logs live in a logs folder inside the Toss install directory. Use toss logs -n 50 for more entries, -path to find the file, or -clear to wipe it.

Features

One command

No accounts, no uploads. Files go straight from your machine to the other device.

Time-limited links

Pick how long the link lives with -t. Toss exits on its own when time runs out.

Streams large files

Files are read from disk in chunks, so big files don't fill up memory. Interrupted downloads can resume.

Live transfer view

See who is downloading, from which app, with progress, speed and time left, refreshed every 3 seconds.

Folders, zipped for you

Share a whole folder. Toss asks, zips it to a temp file, and cleans it up when it exits.

Pull with Toss

toss pull <link> downloads into Toss's own downloads folder with progress and resume.

Activity log

toss logs shows what you shared, who downloaded it, what you pulled, and whether each transfer finished.

Options

toss [-t seconds] [-p port] [-q] [-y] <file|folder>  # share (default 300s, port 8080; -q hides the live view, -y zips folders without asking)
toss pull <link>                                     # download into toss's downloads folder
toss stream <link>                                   # same as toss pull
toss logs [-n count] [-path] [-clear]                # show recent activity
toss update [-check] [-y]                            # update to the latest release
toss -v                                              # show version
